# Design Guidelines for Marcos Kennedy - The Weeknd Tribute Act Website

## Design Approach
**Reference-Based Approach**: Drawing inspiration from modern entertainment and music industry websites like Spotify artist pages and premium booking platforms, with dark, moody aesthetics that reflect The Weeknd's visual brand.

## Core Design Elements

### Color Palette
- **Primary**: Deep purple/magenta (280 80% 20%) for headers and accents
- **Secondary**: Rich red (0 70% 25%) for call-to-action elements
- **Background**: Pure black (0 0% 0%) and dark grays (0 0% 8%)
- **Text**: White (0 0% 100%) and light grays (0 0% 85%)
- **Accent**: Subtle gold (45 60% 65%) for highlights only

### Typography
- **Primary**: Inter or Poppins for modern, clean readability
- **Accent**: Bebas Neue or similar bold condensed font for dramatic headers
- **Body**: 16px base size with 1.6 line height
- **Headers**: Bold weights (600-800) with generous letter spacing

### Layout System
**Spacing**: Consistent use of Tailwind units 4, 8, 12, and 16 (p-4, m-8, gap-12, py-16)
- Generous whitespace for premium feel
- Full-width hero section
- Centered content containers (max-width-6xl)
- Grid layouts for gallery and services

### Component Library
- **Navigation**: Sticky dark header with smooth scroll links
- **Hero**: Full-screen with video background or dramatic imagery
- **Cards**: Dark cards with subtle borders and hover effects
- **Buttons**: Primary (gradient purple-to-red), secondary (outline with blur backgrounds when over images)
- **Forms**: Dark inputs with purple focus states
- **Gallery**: Grid layout with hover overlays

### Visual Treatments
- **Gradients**: Purple-to-red gradients for buttons and accents
- **Shadows**: Deep shadows for depth and premium feel
- **Overlays**: Dark overlays on background images for text readability

## Key Sections
1. **Hero**: Full-screen with performance video/imagery and prominent booking CTA
2. **About**: Split layout with professional headshot and bio
3. **Gallery**: Masonry or grid layout showcasing performance photos
4. **Services**: Clean pricing cards with booking options
5. **Contact**: Simple form with social media integration

## Icons
Use Font Awesome 6 via CDN for consistency:
- Music note icons for performance elements
- Calendar icons for booking
- Social media brand icons
- Location and contact icons

## Images
- **Hero Image**: Large, high-quality performance photo of Marcos as The Weeknd
- **About Section**: Professional headshot
- **Gallery**: 8-12 performance and behind-the-scenes photos
- **Background**: Subtle texture or gradient overlays

## UX Enhancements
- Smooth scrolling navigation
- Loading animations for gallery
- Mobile-first responsive design
- Fast loading with optimized images
- Clear call-to-action hierarchy focusing on booking

This creates a professional, modern tribute artist website that captures The Weeknd's dark aesthetic while maintaining excellent usability for potential clients.
